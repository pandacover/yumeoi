# M1 model decision

Extraction, consolidation, and rerank use OpenRouter via AI Gateway, with OpenAI as fallback. Chat remains GPT-5.6 Luna at reasoning effort `high`.

The eval set is `docs/eval/m1-set.json` (24 hand-labeled documents covering all six memory kinds, plus 12 consolidate cases and 8 rerank cases). Scoring lives in `packages/memory/src/eval.ts`; the live sweep is `apps/app/scripts/eval-m1.ts` (`bun run eval:m1`). Unit tests score the heuristic extractor so CI stays honest without an API key.

A keyed OpenRouter run at `2026-09-08T02:37:32Z` measured every candidate below (OpenAI fallback unused). Raw per-example tokens, cost, and scores: `docs/eval/m1-results.json`.

Winner: **Luna `high`**. F1 is +0.034 over Luna `medium` and +0.076 over Luna `none`. Terra is ~10× the cost with worse quality. Luna `high` still costs $0.00017/doc on this set; revisit at Gmail volume (M5) if reasoning tokens blow up.

## Consolidate (12 cases)

Every candidate scored **accuracy 1.000**. Same-model-as-extract (Luna) therefore picks the cheapest effort: **`none`** ($0.0007, 12.1s, 0 reasoning tokens). Higher efforts only spent more reasoning tokens.

## Rerank (8 cases)

Every candidate scored **nDCG 1.000 / top-1 1.000**. **Luna `none`** wins on cost ($0.0004) and latency (6.9s vs 14.4s for Luna `low`).
