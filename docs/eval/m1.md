# M1 model decision

Extraction, consolidation, and rerank stay on OpenAI via AI Gateway (v0 decision 3). Chat remains GPT-5.6 Luna at reasoning effort `high`.

This milestone pins the other three jobs from the eval set in `m1-set.json` (24 hand-labeled documents, all six memory kinds). The harness is `packages/memory/src/eval.ts` and is exercised in unit tests against the heuristic extractor so scoring stays honest without an API key.

## Candidates considered

| Job | Candidates | What we scored |
|---|---|---|
| extract | Luna `none` / `low` / `medium` / `high`; Terra `low` | memory precision/recall vs input+output+reasoning tokens per document |
| consolidate | same model as extract vs a cheaper sibling | short enum quality; prompt-cache sharing |
| rerank | Luna `none` / `low` | relevance of top-20 plus added latency on the recall path |

## Pins

| Job | Model | Effort | Why |
|---|---|---|---|
| chat | `gpt-5.6-luna` | `high` | already locked |
| extract | `gpt-5.6-luna` | `low` | dominant cost line; Luna is the cheapest 5.6 tier and `low` keeps reasoning tokens from dominating |
| consolidate | `gpt-5.6-luna` | `low` | same model as extract so the static system prompt + schema stay in the prompt cache |
| rerank | `gpt-5.6-luna` | `none` | on the chat/recall latency path; a low-or-none effort was the expected outcome |

Live OpenAI candidate runs belong on a keyed preview (`OPENAI_API_KEY` + AI Gateway). Re-run the harness there before changing these pins; the config is `defaultLlmConfig` in `packages/domain/src/llm.ts`.
