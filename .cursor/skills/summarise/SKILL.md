# Summarise

Summarise the work done or the session and their result or output in simple understandable english with a new subject in a new paragraph.

## When to use

- The user asks to summarise, summarize, recap, or wrap up
- A piece of work has finished and the outcome should be reported
- The session itself should be recapped

## How to write it

- Use simple, understandable English
- Start a new paragraph when the subject changes
- Cover what was done and what the result or output was
- Do not invent facts that are not in the work or session
